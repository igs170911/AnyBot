### 4.4 一輪裡寫紀錄的順序（照寫，不准調換）

所有任務事件：`event_id = EventId::generate(clock)`、`at_ms = clock.now_ms()`、`turn = Some(1)`。任何一次 `append` 失敗 → 立刻回 `Err(TurnError::Record)`，後面什麼都不寫、不送。

1. `UserSaid(UserLine)`（`task = TaskId::generate(clock)`）→ `TaskCreated { goal: 那句話, opened_by: You, bot, parent: None }` → `TurnStarted { turn: 這件任務已有的 TurnStarted 數 + 1, initiator: You { device }, computer, model: 從 primary.endpoint 來, thinking }`。
2. 每一步，照 `turn-loop` S2：
   - ①–④ `checks.rs` 的 `stop_or_cancel()`、`steering()`、`budget()`、`model_switch()`，依序呼叫，都回 `Proceed::Go`（只有這一個值的列舉）。這一版沒有來源，不准做一半。
   - ⑤ 從紀錄讀 `conversation`、`task_events`，照 4.5 組 `BuildInput`，`anybot_context::compile`：
     - `Compiled::Insufficient(i)` → 寫 `TurnEnded { reason: ContextBudget { deficit_tokens: Some(i.deficit_tokens) }, reply_delivered: false }`，結束。不存清單、不寫「組了上下文」、不送。
     - `Compiled::Sent { request, manifest, events }` → `raw.put(serde_json::to_vec(&*manifest)?)` 拿到 `id` → 照 `events` 的順序寫：`Collapsed` 用 `anybot_domain::collapsed_kind`（`CollapseReason` 逐一對到同名的 `ContextCollapseReason`）、`MemoryDropped` 用 `memory_dropped_kind`、`ContextBuilt` 寫成 `ContextBuilt { manifest_id: id.hex(), model, estimate_tokens: manifest.budget.estimate_calibrated }`。
   - ⑥ 先 `request.to_turn_request(tools, thinking, Some(manifest.budget.reserved_output))`（失敗 → `Err(Compile)`，還沒寫「問模型」）→ 寫 `ModelAsked { step: 這件任務已有的 ModelAsked 數 + 1 }` → `ask_plan(&primary, &[], &turn_request, Audience::Watching)`，`plan.bot = &bot.name` → `session.ask`。請求原樣交出，不准再改、再截。
     - `Err(fail)` → 寫 `TurnEnded { reason: 照 4.6, reply_delivered: false }`，結束。
   - ⑦ `Ok(outcome)`：`outcome.handoffs` 每一筆寫 `ModelSwapped { from: before_model, to: after_model, reason: reason_code }`（這一版沒有備用模型，照實寫，不當沒發生）→ 有 `attachment` 就 `raw.put(bytes)` → 寫 `ModelAnswer`（`thinking` 是空字串就 `None`；每個工具要求給一個新的 `CallId::generate`，`provider_call_id` 留模型給的；`ToolArguments::Json` → `ToolArgs::Json`、`Broken` → `ToolArgs::Broken`；`StopKind` 逐一對到 `FinishReason`）→ 寫 `ModelUsage { usage: Absent → None、Present → 五個數照抄, manifest_id: 這一步的 id }`。`outcome.notices`、`skips` 這次只收下，不處理。
   - ⑧ 回答裡每個工具要求，照順序各寫一筆 `ToolNotRun { call_id, reason: NotWired }`；有任何工具要求 → 下一步。沒有 → 寫 `TurnEnded { reason: Answered, reply_delivered: true }`，結束。
3. 結束時回 `Ok(TurnOutcome { task, turn: 1, reason })`。
