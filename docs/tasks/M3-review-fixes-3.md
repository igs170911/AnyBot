## 必修

1. **系統今天自己產生的事件，全部被自己拒絕。**
   - `crates/protocol/src/events.rs` 的 `PROTOCOL_VERSION` 是 1，事件產生時蓋這個值。
   - `crates/protocol/src/versions.rs` 另外定義了一個 `PROTOCOL_VERSION = 2`，版本表只有 v2（2026-01-01），還編了一個 `DEPRECATED_PROTOCOL_VERSION = 1`。
   - 結果：v1 被判成「被 v2 取代，2026-07-01 寬限期到期」。審查的人用真的時鐘產生一個事件再判斷，得到 `Err("不支援的協定版本 1")`。
   - 你把 `events_tests.rs` 改成固定時鐘，剛好把這件事蓋掉了；回報也完全沒寫「協定版本從 1 改成 2」。
   - 要改成：
     - **只有一個** `PROTOCOL_VERSION`，值是 1，只定義在一個地方。
     - 版本表只有 v1。拿掉 v2 和 `DEPRECATED_PROTOCOL_VERSION`。協定的版本歷史是規格的事，**不准自己編**。
     - 測試「被取代的舊版」的規則，用 `accepts_with` 加上測試自己的版本表。
     - 加一個測試：用 `SystemClock` 產生一個事件，再用 `SystemClock` 判斷，必須接受。
     - 拿掉「2001 年接受 v1」這種沒有意義的斷言。
2. **按名字殺程式。**
   - 你跑了 `pkill -f "anybot-server --bootstrap"`。這台電腦上有使用者真的在用的程式，按名字或樣式殺程式可能殺錯。
   - 這次沒有殺到別的程式，但 `AGENTS.md` §一第 9 條已經寫成絕對規則：只准用 PID 收掉你自己啟動的程式。
3. **測試因為真實的日期變紅，代表程式錯了。**
   - 先找出程式哪裡錯，不准把測試改成固定時鐘讓它變綠（`AGENTS.md` §三新加的）。
   - 只有在能說明「測試本身寫錯了」的時候才改測試，而且要寫進回報。
