這一頁把專有名詞各用一句話講完。適合在別頁看到不熟的詞時回來查。

對你的意義：先懂這些詞，其他頁就不用每次重講。

| 詞 | 一句話 |
|---|---|
| AnyBot | 這份軟體。目標是一位可以不理的數位同事 |
| Bot | 一個完整的同事：自己的身分、記憶、技能。換模型不換它 |
| 數位同事 | 可以不理、會跟進、會證明、可以信任。見[[設計理念]] |
| 任務 | 資料庫裡的一件事。有目標、做完的標準、狀態、證據。不只是一段聊天 |
| 做完的標準 | 怎樣算做完。盡量寫成程式查得到的條件，例如檔案在、測試過 |
| 一輪 | Bot 連續做的一段：問模型、做動作、再問，直到要問你或這一段結束 |
| 執行端 | 跑 Bot 的腦的程式。在你的電腦上，或在伺服器上的執行服務 |
| 執行服務 | 伺服器上的那個執行端。跑遠端回合。Bot 不能在這裡跑指令 |
| Bot 的電腦 | 每個使用者一台共用的 Docker。Bot 在這裡跑指令和瀏覽器。沒有金鑰 |
| 桌面 App | Mac、Windows、Linux 的視窗。視窗只是畫面，做事的是背景程式 |
| 手機 | 網頁，可以加到主畫面。不跑腦。一律連伺服器 |
| 聊天頻道 | Slack、Discord、Telegram。只能聊天和看進度，不能按允許 |
| 信任層 | 夾在 Bot 和工具中間。每個動作先把關，再做，再留證據，再驗收 |
| 把關 | 決定這個動作直接做、先問、或拒絕 |
| 核准卡 | 先問你時跳出的那張卡。一張卡只能被答一次 |
| 一律允許 | 你明確允許的一種具體動作，例如「在 Slack 的 #team 發訊息」。別的照問 |
| 安全底線 | 誰都關不掉的規則。危險指令、私密檔、不能點自己的核准按鈕 |
| 六類 | 刪除、寄給別人、分享、發佈、付款、改密碼。預設一定先問 |
| 證據 | 程式從工具的實際回傳記下的紀錄。模型不能自己補 |
| 驗收 | 做完再查一次。能用程式查的，不交給模型 |
| 交付報告 | 做完時產生的報告。每句宣稱連到證據，沒連到就標未驗證 |
| 宣稱等級 | 已驗證、有來源支持、推論、不知道。由程式從證據算出 |
| 未驗收 | 結束了，但系統沒辦法證明。只是標記，不要你做事 |
| 未驗證 | 一句話沒連到證據。交付報告裡會標出來 |
| 判斷來源 | 這句是規則、程式檢查、還是模型判斷 |
| 狀態引擎 | 從事件算出任務現在的狀態。模型說「完成了」不算 |
| 事件 | 只往後加的一筆紀錄。任務狀態由這些筆算出來 |
| 預算 | 一件任務的上限：步數、工具次數、時間、token、花費、重試 |
| 上下文 | 這一次問模型前暫時組出來的內容。不是記憶的正本 |
| 上下文編譯器 | 組上下文的程式。不用自動摘要，放不下就停下 |
| 大腦 | Bot 的記憶：怎麼存、怎麼進來、怎麼搜 |
| 候選 | 模型寫的記憶先放這裡。通過檢查或你確認，才轉正 |
| 模型閘道 | 把各家模型的格式整理成同一種，並處理錯誤和換模型 |
| 資料政策 | 這個 Bot 的資料可以送到哪些模型。只用本機時不送雲端 |
| 備用模型 | 主模型不能用時，照順序換的下一個。最多 8 個 |
| 同步 | 每台留一份副本。對話只往後加。設定以後寫的為準 |
| 匣子 | 這台還沒送到伺服器的紀錄。伺服器回來再補 |
| 信箱 | 伺服器交給某台執行端的工作。一封信只被領一次 |
| 里程碑 | 開發的一段，例如 M5 狀態引擎。做完要檢查全綠 |
| 規格編號 | 行為規格裡的一條，例如 `task-budget`。測試編號像 `T-task-budget-2` |
| 鐵律 | 寫程式的五條硬規則。檢查擋下來的要修，不能關掉 |
| `make check` | 全部檢查關卡。全綠才算這一段做完 |
| `dev` | 整合用的分支。工作做完合這裡 |
| `main` | 主要分支。永遠是檢查全綠的 |
| 工作分支 | `ws/<名稱>`。從 `dev` 切出來，做完合回 `dev` |
| 開發版 | 規格是 `dev` 全綠後產出的安裝檔，跟正式版並存。還沒做 |
| 正式版 | 在 `main` 上打版本標籤才發。還沒做 |
