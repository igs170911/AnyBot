對你的意義：**現在下載得到的是空殼的開發版**。不能拿來聊天，也不能把事情交給它。想參與開發的人，可以從原始碼跑檢查和測試。

## 現在能做什麼

| 你想做的 | 現在 | 狀態 |
|---|---|---|
| 安裝一個 App 來用 | 開發版安裝檔掛在固定的預先發佈頁。打開只看到「畫面骨架：沒有功能」 | ✅ 空殼。下載頁見下面 |
| 跟 Bot 聊天、看任務 | 畫面只有一行「畫面骨架：沒有功能」。手機寬度不橫向捲動，這條已有測試 | 🚧 畫面仍是空殼。`T-phonefit-width-1` 已通過 |
| 看伺服器還活著 | 開發時可以打健康檢查。帳號、同步、信箱有人正在寫，還沒合進 `dev` | 🚧 |
| 跑專案的檢查和測試 | 本機可以。GitHub 每次推送也在 Linux 跑 `make check` | ✅ |

伺服器的命令列認 `--help`、`--version`、`--bootstrap`。`--bootstrap` 指向一個小檔，裡面是資料庫的連線位址。啟動時會印它在聽哪裡，不印密碼。子指令 `reset-password`、`logs`、遷移，列在說明裡，還沒實作。

預設聽本機的 8787 埠（`127.0.0.1` 和 `::1`）。這只是開發時的骨架，不是給人用的服務。

健康檢查是 `GET /v1/health`。它回版本、現在時間、協定版本。不用登入。這份裡還沒有帳號、聊天、任務的 API。帳號那一段有人正在寫，還沒合進 `dev`。

## 從原始碼跑檢查

這一節假設你會基本的命令列。

需要：

| 工具 | 用途 |
|---|---|
| Rust（版本寫在 `rust-toolchain.toml`，目前 1.98.1） | 後端和檢查工具 |
| rustfmt、clippy | 格式和 lint |
| cargo-deny、cargo-machete、cargo-nextest | 授權、沒用到的依賴、測試 |
| Node 22 以上、pnpm | 畫面 |
| gitleaks | 掃金鑰 |
| oasdiff | 看 API 有沒有破壞性變更 |

不要用 Docker 跑測試。測試用的資料庫會下載到這個 repo 的 `target/`，跑完就收。

常用指令：

```sh
make check-fast
```

改完一批就跑這個。它跑最快的關卡：格式、lint、一組較快的測試、依賴方向、鐵律、翻譯、API 文件。

```sh
make check
```

這是「完成」的定義。全部關卡，包含完整測試和端對端。比較久。

關卡各自擋什麼，見[[開發流程]]。

桌面視窗（仍然沒有功能）可以這樣開：

```sh
pnpm install
cargo install --locked tauri-cli
cargo tauri dev
```

手機網頁的骨架：

```sh
pnpm --filter @anybot/web preview
```

打開之後你會看到標題 AnyBot，和一句「畫面骨架：沒有功能」。這是預期的。

## 之後怎麼裝

自動檢查已經在跑（見[[分支與發佈]]）。安裝檔和伺服器映像的流程做好了（✅）。下載到的仍是空殼。

| 版本 | 從哪裡來 | 跟正式版的關係 |
|---|---|---|
| 開發版 | `dev` 檢查全綠後，掛在固定的預先發佈頁。舊的自動換掉 | 用不同的 App 名稱和資料夾，可以跟正式版並存 |
| 正式版 | 在 `main` 上打版本標籤 `v*`，三種系統的安裝檔和伺服器映像 | 先出草稿，檢查後公開 |
| 預先發佈 | 標籤像 `v1.0.0-rc.1` | 標成預先發佈，不是正式版 |

開發版下載頁：<https://github.com/igs170911/AnyBot/releases/tag/dev-build>（標籤 `dev-build`，每次 `dev` 全綠就換上新檔）。伺服器映像在 `ghcr.io/igs170911/anybot`，開發版標 `dev`。

桌面安裝檔這次有：Mac arm64、Mac x86_64、Windows x64、Linux x86_64 的 .deb、.rpm、AppImage。Windows arm64、Linux aarch64 這次沒有桌面安裝檔。伺服器映像有 linux/amd64 和 linux/arm64。

開發版的 App 名稱是 **AnyBot Dev**，識別名稱 `app.anybot.desktop.dev`。正式版仍是 AnyBot、`app.anybot.desktop`。兩份可以裝在同一台電腦，資料夾分開。

個人沒有遠端伺服器時，桌面 App 要在你的電腦裡裝好伺服器和 Bot 的電腦。這台裝不起 Docker，就先只在本機聊天和做事，並說清楚手機和例行任務要等。這也是 📝。

發佈流程的圖在[[分支與發佈]]。

## 還沒簽章時，系統會跳什麼警告

先不簽章（K110）。簽章過的安裝檔是目標，還沒做到。

所以現在裝開發版或正式版時，系統會警告。Release 說明寫了怎麼放行。要不要買 Apple 開發者帳號、Windows 憑證，之後再定。

| 系統 | 你可能看到的 |
|---|---|
| macOS | 這份 App 來自身分不明的開發者，要你到系統設定放行 |
| Windows | SmartScreen 說發行者不明，要你選仍要執行 |
| Linux | 套件沒有簽章，套件管理器會警告。先用 `sha256sum -c SHA256SUMS` 對過再裝。macOS 用 `shasum -a 256 -c SHA256SUMS` |

這些警告是預期的，直到簽章做完。不要為了躲警告關掉系統的安全檢查。
