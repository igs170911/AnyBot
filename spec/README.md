## 最高原則（摘自 04）

1. **數位同事**：可以不理他、主動跟進、主動證明做對了、可以信任。
2. **使用者無感**：一直都可以聊天，結果永遠同步，不用管在哪做，事情都會有人做。
3. **確定性優先**：能用工具、程式、lint 決定的，就不交給模型。
